# CR-2026-10-09 — Changes

Integration of the Core Rules updated on 2026-10-09 (`core-rules-2026-10-09.pdf`, Riot alias `RUP5`). Integrated on 2026-10-30 with `/rules-update`.

## How this version was compared

This is the first Core Rules version committed to the repo. Version 1.4 (2026-03-30), from which the docs were first written, was never added to `docs/rules/` and has no index, so no rule-by-rule diff of the texts is possible. Instead, every rule number quoted in the docs, the `CLAUDE.md` files, the Claude Code commands and the GitHub templates was looked up in `index/CR-2026-10-09.json` and checked against its text.

- Previous version archived: none (no earlier PDF in the repo).
- Index: `index/CR-2026-10-09.json`, 2494 rules (`pnpm foil rules index`).
- Riot's rules patch notes for this release: not in the repo yet; quote them here when they are added.

## Rule content that differs from the docs

| Topic | Rules | What changes for the engine |
| --- | --- | --- |
| First-turn process | 115.2, 485.7, 487.7–491.7 | Defined per mode. 1v1: the player going second channels an extra rune during their first Channel Phase. FFA3, FFA4, 2v2: the player going first skips their first draw and the player going last channels an extra rune. Resolves Q-001. |
| Cleanup | 323.1–323.13 | Ten numbered steps with sub-steps, not eight. Showdowns and combats are first marked Staged (323.7, 323.8), a staged combat can stop being staged (323.9), then the turn player starts a staged showdown (323.11) or combat (323.12). |
| Final point | 473.1.a, 473.1.b.1, 491.8.g | A player 1 point or less from the victory score who conquers without having scored every battlefield this turn **draws a card instead** of the point. The 2v2 mode adjusts the criterion. |
| Victory score | 194.3.a | Modes and card effects may change it. |
| One chain | 330.1 | Explicit rule: only one chain can exist at a time. |
| Draw after Burn Out | 315.4.b.2 | The turn player still draws 1 after the Burn Out. |

## Cross-reference errors in the PDF

Two internal "See rule" references point to the wrong number. The meaning is clear from the text, so these are not rule questions:

- 133.7.a (Champion supertype) says "See rule 103.2.a. Chosen Champion"; the Chosen Champion is 103.3.a.
- 133.7.b (Signature supertype) says "See rule 103.2.d."; Signature cards are 103.3.d.
