# ADR 0016 — Code license

**Status**: To decide
**Date**: 2026-10-30

## Context

The `foilengine` repo is public. Without a license, nobody has the legal right to reuse the code.

## Decision

To choose among: **MIT** (free reuse, including closed source), **AGPL-3.0** (any modified version, even hosted, must publish its code; this is the choice of OpenRift, another open-source Riftbound project), or a source-available license that forbids commercial use (consistent with Riot's constraint, but not open source in the strict sense).

## Consequences

The license only covers Foil's code, never Riot's assets or the card data.
