# ADR 0016 — Licence du code

**Statut** : À décider
**Date** : 2026-10-30

## Contexte

Le repo `foilengine` est public. Sans licence, personne n'a légalement le droit de réutiliser le code.

## Décision

À choisir parmi : **MIT** (réutilisation libre, y compris fermée), **AGPL-3.0** (toute version modifiée, même hébergée, doit publier son code ; c'est le choix d'OpenRift, un autre projet Riftbound open source), ou une licence de type source-available qui interdit l'usage commercial (cohérente avec la contrainte de Riot, mais pas open source au sens strict).

## Conséquences

La licence ne couvre que le code de Foil, jamais les assets de Riot ni les données de cartes.
